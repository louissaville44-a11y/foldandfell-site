Fold & Fell Decorating – website

DEPLOY (Netlify, free):
1. app.netlify.com > Add new site > Deploy manually > drag this whole "site" folder in.
2. Site settings > Domain management > Add domain: foldandfelldecorating.co.uk (and www).
3. In GoDaddy DNS, add the records Netlify shows you. Leave the MX (email) records alone.
4. Netlify will issue the HTTPS certificate automatically.

AFTER LAUNCH:
- Adobe Fonts: make sure foldandfelldecorating.co.uk and www.foldandfelldecorating.co.uk are in the web project domains.
- Send a test enquiry through the form (Web3Forms).
- Google Search Console: add the domain, submit https://www.foldandfelldecorating.co.uk/sitemap.xml
- Google Business Profile: set up / link to the website.
